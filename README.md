# Mizizi Wi-Fi (MVP)
Portal + admin + simulated payments + vouchers. Network control is a mock (no real traffic enforcement yet).
1. Install Node 20+ and Git.  2. `npm install`  3. `copy .env.example .env` (edit SESSION_SECRET)
4. `npm run setup`  5. `npm run dev`  6. Open http://localhost:3000 and http://localhost:3000/admin.html
